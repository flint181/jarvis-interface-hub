# JARVIS Interface Hub

A sleek, futuristic interface inspired by JARVIS from Iron Man. Features smooth animations, glowing effects, and an interactive command center.

## Features

✨ **Sleek UI Design**
- Dark cyberpunk aesthetic with neon blue accents
- Glowing borders and text effects
- Smooth animations throughout

🎬 **Animations**
- Flickering title glow
- Pulsing status indicator
- Wave animation in display
- Floating card icons
- Smooth card hover effects
- Holographic grid background
- Real-time status bar updates

🎯 **Interactive Elements**
- 6 command cards with different functions
- Click animations and ripple effects
- Hover scanning effects
- Real-time system status display
- Typing effect for responses

📊 **System Monitoring**
- CPU, Memory, and Network status bars
- Live status updates
- System health indicators

## Files

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Interactivity and animations
- `README.md` - This file

## How to Use

1. Open `index.html` in your web browser
2. Click on any command card to execute commands
3. Hover over cards to see scanning effects
4. Watch the system status update in real-time

## Customization

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-blue: #0099ff;
    --accent-blue: #00d4ff;
    --dark-bg: #0a0e27;
    /* ... more colors ... */
}
```

### Commands
Add more command cards in `index.html` and their responses in `script.js`.

### Animations
All animations are defined in `style.css` using `@keyframes` rules.
